# UTM Аналитика

Сквозная аналитика по UTM-меткам на Google Таблицах и Apps Script: расход, заявки, квалификация, продажи и окупаемость по каналам. Заявки берутся из amoCRM или облачного Bitrix24, расход — из Meta и ручного ввода. Без серверов и баз данных: всё живёт в Google-аккаунте владельца.

## Установка

Скачай [INSTALL.md](https://github.com/lpshvn-webcode/utm-lite/blob/v1.0.0/INSTALL.md), положи в пустую папку, открой её в Claude Code и напиши: «Установи UTM Аналитику по INSTALL.md».

Как пользоваться и что делать, если что-то не так: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Как устроено

| Часть | Где живёт |
|---|---|
| Страница дашборда (`index.html`) | GitHub Pages, одна на всех: https://lpshvn-webcode.github.io/utm-lite/ |
| Данные, токены CRM и Meta, расчёты (`apps-script/`) | Google Таблица и Apps Script владельца |

Страница обращается к скрипту владельца по коду из ссылки (`#<код>`) и паролю. Токены CRM и Meta наружу не отдаются. Имена и телефоны из CRM не забираются. В CRM продукт ничего не пишет.

## Своя копия страницы

Страница универсальная и не содержит данных. Если не хочешь зависеть от этого репозитория, сделай форк и включи в нём GitHub Pages: ссылка на дашборд станет `https://<твой аккаунт>.github.io/<репозиторий>/#<тот же код>`.
